# Claude Ecosystem Research

Bu proje, Anthropic Claude ekosisteminin kurumsal kullanım potansiyelini araştırmak amacıyla hazırlanmıştır.

Çalışma kapsamında;

- Claude Skill yapıları
- Model Context Protocol (MCP)
- Prompt Engineering teknikleri
- Workflow tasarımları

incelenmiş ve örnek kullanım senaryoları hazırlanmıştır.

# Proje Amacı

Yapay zekâ asistanlarının kurum içi süreçlerde nasıl kullanılabileceğini değerlendirmek ve Claude ekosisteminin;
